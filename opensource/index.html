02 / 常见问题

开始之前。

阅读 Community 进展 ↗
APIGO 开源项目与 apigo.ai 是什么关系？＋

开源项目面向希望自行构建基础设施的团队；apigo.ai 提供现有托管云 MaaS 服务。两者服务不同的使用方式，并不表示所有云端能力均已开源。

整套平台都会开源吗？＋

不会。Community 计划开放网关、基础控制面与团队管理等基础能力。Lyra 智能引擎、自动编排与商业策略保持闭源。

现在可以部署 Community 吗？＋

项目正在分阶段开放。正式部署说明、发行包和许可证以 GitHub 仓库实际发布的文件为准；本页不构成对任何组件的许可授予。

企业私有化是否包含商业能力的源代码？＋

企业方案可评估私有环境中的商业能力授权；Lyra 以闭源容器或二进制形式交付，不提供引擎源码。范围、升级与服务承诺以合同为准。

如何参与开源建设？＋

可以在 GitHub 关注 apigo-labs，查看各仓库说明，通过 Issue 反馈使用场景，或为已开放的代码和文档提交 Pull Request。贡献规则以对应仓库说明为准。
