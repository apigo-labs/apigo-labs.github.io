02 / 云端接入

沿用熟悉的 OpenAI SDK

  1. 创建账号与 API Key

    前往 APIGO Cloud ↗，登录后在 Workspace 创建 API Key。

  2. 选择可用模型

    在模型目录 ↗确认模型 ID、可用性与价格。账号余额及模型访问条件以云平台为准。

  3. 设置环境变量并发送请求

    安装 Python SDK：pip install openai。设置 APIGO_API_KEY 和 APIGO_MODEL，然后运行下方示例。

Python / 云平台接入示例 
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.apigo.ai/v1",
    api_key=os.environ["APIGO_API_KEY"],
)

response = client.chat.completions.create(
    model=os.environ["APIGO_MODEL"],
    messages=[
        {"role": "user", "content": "你好，APIGO"}
    ],
)
print(response.choices[0].message.content)

将 API Key 保存在服务端环境变量中，不要嵌入公开网页。示例会产生真实模型请求，使用费用以云平台定价为准。
